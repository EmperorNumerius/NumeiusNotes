## 2024-08-03 - Replaced GestureDetector with IconButton in home_page.dart
**Learning:** Replaced bare `GestureDetector` widgets with standard `IconButton` on standard icons (like `Icons.more_horiz_rounded`) providing built-in tooltips on hover (desktop/web) and accessibility improvements. When replacing standard icon `GestureDetector`s in Flutter UI layout that is already tight or precise, using `padding: EdgeInsets.zero` and `constraints: const BoxConstraints()` on `IconButton` prevents the button from changing size and causing layout regressions. In the same view, standard layout widgets missing `Expanded` can cause RenderFlex overflow tests to fail. Fixed `NumeiusNotes` App Title overlapping bounds on narrow displays by adding missing `Expanded` widget and using `TextOverflow.ellipsis`.
**Action:** Always verify `Expanded` usage when modifying headers that shrink in widget tests, and explicitly disable `padding` and default `constraints` on `IconButton` when substituting `GestureDetector` to preserve UI spacing limits and prevent RenderFlex issues.

## 2026-10-02 - Replaced GestureDetector/InkWell with IconButton for standard icons
**Learning:** In Flutter's standard icon buttons, wrapping `GestureDetector` or `InkWell` around an `Icon` is functionally okay but misses out on accessibility tools like tooltips and default keyboard focus indicators unless manually added. Meanwhile, `IconButton` requires careful constraint handling (e.g., using `BoxConstraints` and `padding: EdgeInsets.zero`) when used in tight UI areas (like `TabManager`) to avoid breaking the layout flex while retaining accessibility features.
**Action:** When replacing custom-built icon buttons with `IconButton` in dense UI components, explicitly override the padding and provide tight constraints (`minWidth`, `minHeight`) to preserve visual alignment and prevent `RenderFlex` overflow errors.

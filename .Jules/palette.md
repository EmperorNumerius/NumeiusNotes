## 2024-06-25 - IconButton vs GestureDetector for accessibility
**Learning:** In Flutter, replacing a `GestureDetector` that wraps an `Icon` with an `IconButton` significantly improves accessibility natively. It provides a standard 48x48 accessible touch target size (via default padding and constraints), enables tooltip support for screen readers via the `tooltip` property, and provides built-in visual hover/focus states for web/desktop platforms, without needing custom `BoxConstraints` or `Tooltip` widget wrappers. However, applying `IconButton` requires paying attention to parent widget constraints, as its larger intrinsic padding can induce `RenderFlex` overflows in horizontally constrained layouts (e.g., sidebars) which need to be resolved by expanding the sibling elements.
**Action:** Always prefer `IconButton(tooltip: '...', icon: Icon(...))` over `GestureDetector(child: Icon(...))` for standalone actionable icons in Flutter to ensure accessible touch targets and screen-reader support out of the box. Ensure sibling components in `Row`s are wrapped in `Expanded` or `Flexible` to absorb the padding safely.

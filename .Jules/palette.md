## 2026-06-08 - Adding Tooltips to Icon Buttons
**Learning:** In Flutter, using `Tooltip` wrappers is the equivalent of adding ARIA labels for accessibility on icon-only interactive elements like `InkWell` and `GestureDetector`.
**Action:** Always wrap icon-only interactive UI elements with a `Tooltip` containing a clear, descriptive `message` to ensure screen reader compatibility and mouse hover discoverability.

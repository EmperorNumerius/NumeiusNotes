## 2024-08-20 - Palette UX improvements
**Learning:** In Flutter, wrapping an icon-only button inside a `GestureDetector` loses out on native accessibility features and standard touch targets. When replacing `GestureDetector` with `IconButton`, do not use `padding: EdgeInsets.zero` or strict `BoxConstraints()` as the default `IconButton` allows the standard 48x48 accessible touch target and native hover/tooltip support. When fixing `RenderFlex` overflows in tests by wrapping an element in `Expanded`, ensure the UI visually requires that expansion (e.g. app titles in constrained headers) and use `overflow: TextOverflow.ellipsis` to handle long content gracefully.
**Action:** Replace custom touch wrappers around icons with `IconButton` and its `tooltip` property to natively support a11y standards and mouse hover states without extra wrapper widgets.

## 2024-08-20 - Palette UX improvements CI Fix
**Learning:** The CI pipeline in this project treats `flutter analyze` info-level lints (such as deprecated member usage, missing curly braces in flow control) as fatal failures across the entire repository. Even if they exist outside the modified lines, they will fail the GitHub Action. Always run a full `flutter analyze` and resolve simple formatting or linting errors (like `curly_braces_in_flow_control_structures` and `deprecated_member_use`) introduced by flutter framework updates before submitting PRs.
**Action:** When fixing unrelated UX issues, ensure all deprecated warnings and basic Dart lints in related widgets or controllers (like `ai_settings_dialog`, `tab_manager`, and `calculator_block`) are suppressed with explicit `// ignore:` tags or structurally fixed (adding curly braces) to keep the CI suite green.
